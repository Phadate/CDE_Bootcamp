# CDE_Bootcamp GIT and Linux assignment

## Overview

This repository contains scripts and data used for a small data engineering / ETL bootcamp project. It includes raw survey data, a simple transformation pipeline, and example outputs.

## Repository structure

- [move_file.sh](move_file.sh): A helper shell script (likely moves or organizes files).
- [pipeline.sh](pipeline.sh): Main pipeline script.
- [README.md](README.md): This file.
- Gold/: Directory containing gold-standard or final outputs.
	- 2023_annual_survey.csv
- raw/: Raw input data.
	- annual_survey.csv
- Transformed/: Transformed outputs generated by the pipeline.
	- 2023_annual_survey.csv
 - json_and_CSV/: containing jsons and csv moved from the source folder.
	- 2023_annual_survey.csv
   	- test.json

## Prerequisites

- Unix-like shell (Git Bash, WSL, or macOS/Linux terminal) on Windows.
- Bash available in your PATH.
- Basic POSIX utilities (`mv`, `cp`, `awk`, `sed`, etc.) depending on what the scripts use.

If you plan to run or modify the pipeline, ensure you have a bash-capable environment. Git Bash or WSL on Windows is recommended.

## Quick Start

1. Inspect the raw data:

```bash
head -n 5 raw/annual_survey.csv
```

2. Run the pipeline (from repository root):

```bash
bash pipleline.sh
```

3. Verify outputs in `Transformed/` and `Gold/`:

```bash
ls -l Transformed Gold
```

Notes:
- If `pipleline.sh` is not executable, run `bash pipleline.sh` as shown above.
- Inspect `move_file.sh` to understand any file-movement behavior before running it.

## Files and Purpose

- **raw/annual_survey.csv**: Raw survey data source.
- **pipleline.sh**: Orchestrates transformation steps to produce cleaned/transformed data into `Transformed/` and/or `Gold/`.
- **move_file.sh**: Utility to move or archive files — review before running.
- **Transformed/2023_annual_survey.csv**: Output from the transformation pipeline.
- **Gold/2023_annual_survey.csv**: Final output or gold-standard file used for verification.

## Typical workflow

- Make a backup of raw data.
- Run the pipeline: `bash pipleline.sh` or `./pipeline.sh`
- Compare `Transformed/2023_annual_survey.csv` with `Gold/2023_annual_survey.csv` to validate results.

Example diff command:

```bash
diff -u Gold/2023_annual_survey.csv Transformed/2023_annual_survey.csv | less
```

## Troubleshooting

- If a script fails with permission errors, ensure execution permission or run with `bash scriptname`.
- If expected files are missing, inspect `pipleline.sh` for hard-coded paths.
